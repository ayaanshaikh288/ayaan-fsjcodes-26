# Ayaan Personal Portfolio

A responsive personal portfolio website built with:
- HTML
- CSS
- JavaScript

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — real-time form validation and success message

## Run
Open `index.html` in any modern browser.

The contact form is front-end only. It validates fields and displays a success message without reloading the page; it does not send email to a server.
